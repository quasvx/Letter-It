LETTER-IT

Tu API rápida y sin complicaciones para generar favicons dinámicos al vuelo. Solo pasa tu URL y obtén una inicial en SVG lista para usar.

https://letter-it.pages.dev/faviconV2?
url=https://quasvx.cc.cd&
size=256

¿Cómo funciona?
El endpoint /faviconV2 agarra el parámetro url, extrae la primera letra de tu dominio, le asigna un color de fondo aleatorio y te devuelve una imagen lista para incrustar.

⚡ Rápido (Cloudflare Edge) 🎨 SVG Nativo 📏 Tamaño Personalizable
