Letter-It

Simple, fast favicon generation at the edge.
/faviconV2?url=https://google.com&size=128
google.com → G
github.com → G
⚡ Edge Cloudflare Workers 🎨 SVG Native vector 📏 Custom Size parameter 🔲 Square Clean design

How it works: The endpoint extracts the first letter from your domain, assigns a random background color, and returns an SVG image ready to use as a favicon or avatar.


Parameters:
url — The domain to generate the favicon for
size — Output size in pixels (default: 256)
